# Хендовер для дизайнера

Покрокова інструкція першого запуску плагіна **plusone-creative**. Розрахована на ~15 хвилин від нуля до першого згенерованого посту.

> Усе нижче — одноразова установка. Після першого запуску просто пишеш промпт у Cowork, і воно працює.

---

## Що тобі знадобиться

- **Mac або Windows** з встановленим **Claude Desktop** (план Pro або Max — не Free).
- **Аккаунт Figma** з доступом до проекту, який ти хочеш брати за стилевий референс.
- **Аккаунт Higgsfield** з ненульовим балансом (потрібно ~2 кредити на креатив).
- **Доступ до терміналу** — у Windows це PowerShell, у Mac це Terminal.app. Не лякайся, треба буде ввести 2 команди.

---

## Крок 1 — Підключити Figma у Claude Desktop

1. Відкрий Claude Desktop.
2. У лівому нижньому кутку натисни своє ім'я → **Customize** (або **Settings → Customize**).
3. У меню зліва вибери **Connectors**.
4. Знайди **Figma** у списку → натисни **Connect**.
5. Відкриється Figma у браузері з запитом дозволу → **Allow access**.
6. Повертайся у Claude Desktop. Біля Figma має бути зелена позначка **Connected**.

Якщо нема — повтори, перезавантаж Claude Desktop, спробуй ще раз. Якщо все одно ні — напиши Vasyl-у скрін.

---

## Крок 2 — Підключити Higgsfield там же

1. У тому ж меню **Customize → Connectors**.
2. Знайди **Higgsfield** → **Connect**.
3. Браузер → **Allow access**.
4. Зелена позначка **Connected** біля Higgsfield.

Перевір баланс — у Higgsfield дашборді має бути хоча б 20 кредитів для першого тесту.

---

## Крок 3 — Встановити плагін через термінал

Відкрий термінал (PowerShell на Windows / Terminal на Mac) і встав ці дві команди по черзі:

```
claude plugin marketplace add HoshovskyiV/plusone-creative
```

Натисни Enter. Має вивести `Added marketplace...`.

```
claude plugin install plusone-creative@plusone-creative
```

Натисни Enter. Має вивести `Installed plusone-creative`.

Перевірка:

```
claude plugin list
```

В списку має бути `plusone-creative`.

> Якщо команда `claude` не знаходиться — у Claude Desktop **Settings → Use Claude Code** має бути увімкнено, і термінал може потребувати перезапуску.

---

## Крок 4 — Перший промпт у Cowork

1. У Claude Desktop відкрий вкладку **Cowork** (зверху).
2. Створи новий чат.
3. Скопіюй цей готовий промпт (заміни URL на свій тестовий Figma):

```
Зроби 3 інстаграм-пости у стилі проекту https://www.figma.com/file/<твій-id>.
Контент:
1. Хедлайн "Понеділок", підзаголовок "Новий тиждень — нові ідеї", дудл — стрілочка вгору, фото — людина за ноутбуком.
2. Хедлайн "Середа", підзаголовок "Половина пройдена", дудл — півколо, фото — філіжанка кави.
3. Хедлайн "П'ятниця", підзаголовок "Майже там", дудл — серце, фото — захід сонця.
Формат 1080×1080.
```

4. Натисни Enter.

---

## Крок 5 — Як зрозуміти що відбувається

Claude буде звітувати по ходу. Очікувані повідомлення (в такому порядку):

1. *"Аналізую стиль проекту..."* — запустився `style-analyzer`. ~30 секунд.
2. *"Style profile витягнуто: дудли — ..., фото — ..., палітра — ..."* — стиль розпізнано.
3. *"Будую матрицю 3×4..."* — content matrix.
4. *"Генерую 6 асетів через Higgsfield..."* — `asset-generator` працює паралельно. 1–2 хвилини.
5. *"Складаю кадри у Figma..."* — `frame-composer` пише у твій Figma-файл.
6. *"Валідую кадри..."* — `validator` робить screenshot-перевірку.
7. *"Готово. Ось лінки:"* — фінальний звіт з URL.

Якщо щось зупинилось на середині — Claude скаже **на якому кроці** і **що зробити**. Зазвичай — підтвердити дозвіл на write у Figma або поповнити Higgsfield.

---

## Крок 6 — Як інтерпретувати результат

У фінальному повідомленні буде:

- **Лінки на готові кадри** — кожен відкриває конкретний фрейм у Figma. Усі вони лежать на новій сторінці `Generated — <дата>` твого Figma-проекту. Оригінальний шаблон не зачеплено.
- **Список "потрібна ручна доводка"** — якщо `validator` знайшов проблеми, які retry не виправив. Зазвичай: занадто довгий заголовок або дудл попадає на лого.
- **Список warnings** — те, що Claude не зміг автоматично визначити (наприклад, "у проекті немає Variables collection — використав raw hex").

---

## Що треба буде дотягувати руками

Перший pilot — це v0.1.0. Очікувано що нижче треба буде ловити:

| Проблема | Що зробити |
|---|---|
| Текст не помістився в контейнер | Скоротити копію або у Figma вручну зменшити text style |
| Дудл стоїть криво | Перетягнути в Figma руками |
| Фото не в тому кропі | Перенастроїти image-fill scale у Figma |
| Дудл з білим фоном замість прозорого | Видалити фрейм, запустити `плагін регенерує дудл №X` окремо |
| Стиль вийшов «не той» | Перевірити чи правильний Figma URL — він має вести на проект з готовими постами, не на dribbble-варіант |

---

## Якщо щось зовсім не працює

1. **`claude plugin list` нічого не показує** — перевстанови: `claude plugin uninstall plusone-creative` → знову `claude plugin install ...`.
2. **Figma пише "permission denied"** — у твоєму Figma-проекті ти маєш бути в ролі **Editor**, не **Viewer**.
3. **Higgsfield пише "insufficient balance"** — поповни баланс у Higgsfield дашборді.
4. **Cowork не бачить плагін** — перезапусти Claude Desktop повністю (Quit, не Close).
5. **Будь-яка інша помилка** — скрін + текст помилки у чат до Vasyl-а.
